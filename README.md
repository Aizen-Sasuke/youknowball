# YouKnowBall

A football quiz you can play with friends. Each round shows five clues about a player, in a random order. The fewer clues you need, the more you score.

## Modes

- **Classic**: pass the phone around, with an optional turn timer, teams, and a letter-hint lifeline.
- **Solo**: you against the clock, one run, three strikes, personal best.
- **Wordle**: six tries, colour hints for league, nation, position, club and birth year.
- **Grid**: fill a 3×3 board where a club row meets a nation column.
- **Career path**: clubs unlock one at a time, initials last.
- **Daily**: the same five players for everyone each day, with a shareable result grid.
- **Online**: host a room, share the 4-to-6 character code (or an invite link), and race friends on their own phones.

## Challenges

Any round set is a link. Every game is generated by a seeded PRNG: a "Challenge a friend" button (on end screens and in shared results, see below) copies a link with `?seed=<code>&m=<mode>` plus the options that shape the deck (`r` rounds, `j` solo run length, `p` pool, `gd` grid difficulty). The same seed, mode and pool produce the exact same rounds on every device and reload; the Daily is the same mechanism with the date as the seed (fully reproducible offline). A short banner ("You are playing a challenge · SEED ABC123") with a "Create your own" button shows while a challenge is active, and a dated Daily can be opened directly with `?d=YYYY-MM-DD`. Online rooms are already identical-rounds for everyone (the host generates the deck); hosts can additionally pin a "room seed" so two rooms with the same settings play the same deck.

**279 players** (162 current stars, 117 legends), difficulty tiers with bonus points, streaks, stats saved on your device, sage light and dark themes, a stadium intro, and an offline-capable PWA shell.

## Run it

It is a static site with no build step. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New, then Project, and import the repository.
3. Set the framework preset to Other and leave the build command empty.
4. Deploy. Online rooms work as soon as the site is live over HTTPS.

Or from this folder: `npx vercel --prod`.

## Offline / PWA

The site registers a small service worker (`sw.js`): the app shell (HTML, CSS, JS, icons, manifest) is precached, and Google Fonts plus the PeerJS CDN are cached at runtime. After one online visit the game loads offline. Online rooms still need a live connection, obviously.

## How online play works

Online rooms use [PeerJS](https://peerjs.com/) (WebRTC) with its free public signaling server. The host's browser runs the game and everyone else connects to it, so there is no backend to run.

Some strict networks block direct connections. If a friend cannot join, add a TURN relay in `config.js`.

## Notes

- Player facts are written from memory and may contain mistakes. Open an issue or edit the data in `js/data.js` (the `RAW`, `SPR` and `LG` blocks). Recomputed by `node tools/data-audit.js` (parses the three blocks directly): 279 rows, no duplicate names, league tags cover all 279 players — spread PL 121, LL 69, SA 46, BL 21, L1 14, OT 8 — and all 32 special-clue entries resolve to real players. The thinnest pool is **OT** ("other", 8 players, all of them legends) — contributions welcome there.

## Structure

- `index.html`: markup shell · `manifest.webmanifest` + icons: installable app
- `sw.js`: offline service worker · `404.html`: friendly 404 (Pages + Vercel)
- `css/main.css`: the whole visual layer (Matchday Lower-Third)
- `js/data.js`: player data · `js/fx.js`: presentation helpers (fit, FLIP, pulse, tween) · `js/app.js`: game logic and screens
- See `REDESIGN.md` for changelog, test checklist and fragile-code notes.
