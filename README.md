# YouKnowBall

A football quiz you can play with friends. Each round shows five clues about a player, in a random order. The fewer clues you need, the more you score.

## Modes

- **Classic**: pass the phone around, with an optional turn timer, teams, and a letter-hint lifeline.
- **Solo**: you against the clock, one run, three strikes, personal best.
- **Wordle**: six tries, colour hints for league, nation, position, club and birth year.
- **Grid**: fill a 3×3 board where a club row meets a nation column.
- **Career path**: clubs unlock one at a time, initials last.
- **Daily**: the same five players for everyone each day, with a shareable result grid.
- **Online**: host a room, share the 4-to-6 character code (or an invite link), and race friends on their own phones.

## Challenges

Any round set is a link. Every game is generated by a seeded PRNG: a "Challenge a friend" button (on end screens and in shared results, see below) copies a link with `?seed=<code>&m=<mode>` plus the options that shape the deck (`r` rounds, `j` solo run length, `p` pool, `gd` grid difficulty). The pool is one value: `x` everyone, `0`/`1` current stars or legends, a league code (`PL`, `LL`, `SA`, `BL`, `L1`, `OT`), `n:<nation>` (e.g. `n:Brazil`) or `y:<birth decade>` (e.g. `y:1980`). The same seed, mode and pool produce the exact same rounds on every device and reload; the Daily is the same mechanism with the date as the seed (fully reproducible offline). A short banner ("You are playing a challenge · SEED ABC123") with a "Create your own" button shows while a challenge is active, and a dated Daily can be opened directly with `?d=YYYY-MM-DD`. Online rooms are already identical-rounds for everyone (the host generates the deck); hosts can additionally pin a "room seed" so two rooms with the same settings play the same deck.

**306 players** (169 current stars, 137 legends), difficulty tiers with bonus points, streaks, stats saved on your device, sage light and dark themes, a stadium intro, and an offline-capable PWA shell.

## Run it

It is a static site with no build step. Open `index.html` in a browser, or serve the folder:

```
npx serve .
```

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, choose Add New, then Project, and import the repository.
3. Set the framework preset to Other and leave the build command empty.
4. Deploy. Online rooms work as soon as the site is live over HTTPS.

Or from this folder: `npx vercel --prod`.

## Offline / PWA

The site registers a small service worker (`sw.js`): the app shell (HTML, CSS, JS, icons, manifest) is precached, and Google Fonts plus the PeerJS CDN are cached at runtime. After one online visit the game loads offline. Online rooms still need a live connection, obviously.

## How online play works

Online rooms use [PeerJS](https://peerjs.com/) (WebRTC) with its free public signaling server. The host's browser runs the game and everyone else connects to it, so there is no backend to run.

Some strict networks block direct connections. If a friend cannot join, add a TURN relay in `config.js`.

## Notes

- **Filter the deck.** Classic, Career path, Solo and Online share one "Players" picker with grouped options: Everyone, Current stars, Legends, a league, a nation or a birth-decade era. The value lives in `cfg.pool` and is read by one predicate (`inPool`) used by both the deck build and the Grid generator, so a filtered game is still a seeded, shareable round set — the `p` parameter carries the filter (`n:Brazil`, `y:1980`, …). The picker is a single native `<select>` with `<optgroup>`s (keyboard- and phone-friendly); any non-default filter shows a status bar with the match count and a one-click **Clear filter**, so a thin pool is visible before you start (a pool of 0 shows a message naming the filter and returns to Setup instead of crashing).

- Stats include a chalk **guess distribution**: how many rounds you solved at clue 1–5, per clue-based mode (Classic, Career path, Daily, Solo and Online). One increment per solved round — a replay of an already-played Daily never reaches play, so it cannot double count, and give-ups never count. The bars carry a text summary for screen readers. Counts live in the existing `ykbs` stats store (`ST.dist`), not a second one.

- Stats also carry a small set of **badges** (12), derived from those same counters: first solve, five-clue comeback, a five-turn streak, Wordle in one, 100 solves, one per league mastered and an all-era explorer. Nothing is tracked in a second store — `ST.ach` only records *when* a badge was earned, and two small counters (`ST.lg`, `ST.era`) record solved players per league and per birth-decade. Every badge shows a text label plus either its requirement or "Earned &lt;date&gt;"; meaning is never carried by colour alone, and unearned badges stay listed so the goal is always visible. Earning one raises an `aria-live` toast. The same screen has a **Share profile card** button: it draws a canvas card (games played, players solved, best streak, fastest solve, daily streak and the earned badge names) with the same `cardImg` helper the Daily/Wordle/Grid result cards use, so where canvas is unavailable it falls back to sharing a plain-text profile instead.

- After every round reveal (Classic, Career path, Solo, Daily and Online) and on the Wordle result screen a compact **player card** shows the answer: nationality, position, birth year, **current club** (or **Retired** where Wikidata says so), league, clubs, tier (★ / ★★) and the fact line, plus a "Learn more" link to a Wikipedia search. It is built from the same fields the clues are built from, so it cannot disagree with the round. League codes are labelled from one shared map (`LGL`: PL → Premier League, LL → La Liga, SA → Serie A, BL → Bundesliga, L1 → Ligue 1, OT → Other) used by the card, the Wordle "League" column and every pool picker. The Wikipedia link is the only absolute URL in the app; all site assets stay relative.

- If you leave a **Classic, Career path or Solo** game mid-round, Home offers **Resume** on your next visit (it never resumes on its own; there is a **Discard** button next to it). The snapshot lives in the existing `ykbs` store (`ST.rg`, versioned) and holds the round set, scores, turn, clue index, the current round's five clues and the game's seeded order. Resuming restarts the current round's timer but keeps your elapsed time, so a paused round cannot set a "fastest solve" record. Online games are not resumable (the host owns the room). The snapshot is dropped when the game ends or you quit it.

- Data integrity is gated in CI: `tools/validate-data.mjs` (dependency-free Node ESM) asserts the row count, uniqueness, league-tag coverage, league codes, special-clue resolution, tier values, the Wikidata `DATA_UPDATED` date and that every `CURRENT` current-club entry resolves to a real player in `js/data.js`; `.github/workflows/validate.yml` runs it on every push and pull request. The shipped site stays zero-build. Run `node tools/validate-data.mjs` locally.

- **Current club / freshness.** `js/data.js` ends with a machine-written block: `DATA_UPDATED` (the date the profiles were last checked against [Wikidata](https://www.wikidata.org/)) and `CURRENT`, a player-name → current-club map (`"Retired"` for retired players, omitted when the evidence is ambiguous). The player card shows it and the Stats screen prints the `DATA_UPDATED` date under "Your stats on this device", so staleness is visible rather than implied. Both are regenerated offline by `pipeline/enrich_players.py` (see `pipeline/README.md`); nothing is fetched at runtime. Current clubs are a point-in-time snapshot and do change.

- Player facts are written from memory and may contain mistakes, **except** the machine-written ones: clues whose label is `Auto` (the `fact` field reads `Auto~…`, using the same `Label~Text` shape as the special clues) are built from Wikidata's structured fields by `pipeline/add_players.py` and can be replaced with a hand-written fact at any time. Open an issue or edit the data in `js/data.js` (the `RAW`, `SPR` and `LG` blocks). Recomputed by `node tools/data-audit.js` (parses the three blocks directly): 306 rows, no duplicate names, league tags cover all 306 players — spread PL 121, LL 69, SA 46, BL 29, L1 23, OT 18 — tier split 169 stars / 137 legends, and all 32 special-clue entries resolve to real players. The thinnest pool is still **OT** ("other", 18 players) — contributions welcome there.
